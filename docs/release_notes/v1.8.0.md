# OpenPhase v1.8.0

v1.8 adds three teaching labs, explains every engine diagnostic code in plain
language, makes error messages and keyboard focus clearer, and documents a
near-critical limitation of the stability test with a reproducer and a
proposal. The Peng–Robinson engine, the validation record and the golden
master are unchanged.

## Teaching

- **Lab 5: liquid density and volume translation**, **Lab 6: phase stability
  and the flash** and **Lab 7: the critical point, the envelope and retrograde
  condensation**, each with an instructor key. The app now links seven
  teaching labs.
  - Lab 6 covers the tangent-plane distance, Rachford–Rice by hand, and Wilson
    versus converged K-values.
  - Lab 7 covers the certified critical point, the cricondenbar and
    cricondentherm, and retrograde condensation at 327 K.
  - Both labs show honestly where the stability test calls a state inside the
    envelope "single phase" near the critical point.
- One new Learn-mode exercise each for Labs 5, 6 and 7. Every number in the
  labs, the keys and the exercises is recomputed from the engine by a test.

## App

- **Diagnostic codes in plain language.** The Diagnostics page lists all 42
  codes the engine can report, each with one sentence of explanation. The
  flash diagnostics table gains a "Meaning" column. The codes and the
  engine's own messages are still shown verbatim. A test reads the codes from
  the engine, so a new code cannot appear without an explanation.
- **Clearer error messages.** A refused case file now says how to get a valid
  one, and an all-zero composition says what to enter.
- **Visible keyboard focus.** Sidebar page links and input fields show a solid
  focus ring in the theme colour.

## Engine findings (no engine change)

- **P12, near-critical false "stable" verdicts.** For 50/50 methane/propane
  at 8.534 MPa, the flash reports a single stable phase from 314 K to 320 K,
  although the extended phase envelope places those states inside the
  two-phase region. Both stability trials return the trivial solution there.
  `tools/reproduce_near_critical_false_stable.py` shows it; proposal P12
  suggests extra trial starts near the feed. It waits for the owner's
  decision.

## Known limits

- **One experimental source.** Every validation state comes from May et al.
  (2015). No second source has been downloaded yet.
- **Dew points.** Methane + propane has a unique dew answer at 1 of 23
  measured states. At most of the others PR has two dew pressures, and the app
  reports none, by design.
- **Near-critical stability (P12).** Close to a mixture critical point, a
  "single phase" result can be wrong; check it against the phase envelope.
- **Volume translation is not validated for mixtures.** The shifts are
  fitted to pure saturated liquids only.
- **Components C1–C3 only.** The butanes wait for the owner's Table 5 values
  (draft PR 47); CO2 and N2 exist only as a plan.
- **The first phase envelope of a case takes about one to three minutes**,
  depending on how busy the server is; repeating the same case is answered
  from the cache.
